# FLSHGAT-for-semi-supervised-fault-diagnosis
This is the code that implements method in “Feature–label similarity-aware hypergraph attention network: a semi-supervised fault diagnosis method for machinery under extremely low label rate scenarios”
Label propagation algorithms (LPAs) and graph neural networks (GNNs) are semi-supervised learning models that have yielded satisfactory results in machinery fault diagnosis under limited labeled data conditions. However, LPAs consider only label similarity, while GNNs primarily focus on feature similarity, and both encode pairwise connections that inherently fail to capture high-order correlations, consequently limiting the ability to make full use of scarce labeled and massive unlabeled data. To address the above limitations, this paper proposes a novel semi-supervised learning model, named feature–label similarity-aware hypergraph attention network, to jointly model high-order feature and label similarities for machinery fault diagnosis under extremely low label rate scenarios. Firstly, a hypergraph of all samples is constructed to encode their high-order correlations beyond pairwise connections. Then, a hypergraph attention network is constructed, in which a cross-attention mechanism is employed to adaptively learn the importance weights of node–hyperedge interactions, facilitating propagation and aggregation of class-specific features along hyperedges from both labeled and unlabeled samples. Subsequently, a hypergraph LPA is integrated into the proposed framework, propagating label information from labeled samples to their neighbors, to fully exploit scarce label information. Finally, the semi-supervised fault diagnosis model is jointly optimized by imposing supervised constraints on classifier predictions and propagated labels for labeled samples, along with a consistency constraint between them for unlabeled samples. Experimental results on three machinery fault diagnosis datasets demonstrate that the proposed method achieves superior diagnostic accuracy compared with the state-of-the-art approaches, especially when the label rate is as low as 1%. The related code was released at https://github.com/xinswjtu/Pseudo-label-SSAEL.
